# Dual-monitor assets (16-frame prototype mapping)

Generated by `examples/render_beam_monitors.py` from
`vqc_workbench.ladder.prototype`: Workbench `spiral_phase` masks, the
modal LG projector (`simulate_modes` / `lg_mode_xy`), and analytic
LG_{0,ℓ} z-propagation (w(z), Gouy-twisted Poynting helix) for the
length views. Dark-background intensity / phase displays — not marketing
stills. Fallback procedurals live in `ladder.frames` if a PNG is missing.
